claude-visual-review · Windows + VS Code

Set up visual review with your agent

Claude Code brings you decisions, sign-offs and reports in the Plannotator Inbox, where you read them and click Approve or Change. Your answer goes straight back to the session that asked. Your own agent installs it with you; it takes about ten minutes.

Paste this into Claude Code

Claude Code · VS Code terminal
> Set up claude-visual-review for me. Read https://raw.githubusercontent.com/pmcormier/claude-visual-review/main/docs/setup-prompt.md and follow it step by step: it walks you through installing it with me. Ask me before changing anything on my machine, and show me the installer's Summary at the end.

Your agent reads the full instructions from the repo, so you always get the current version. Paste the same prompt again later to update.

Before you start

  • Windows required
  • PowerShell 7 (pwsh) required
  • VS Code required
  • Claude Code required
  • git and Python required
  • uv BMAD only

Your agent checks these first and tells you how to get anything missing.

What happens

0 of 7 done

  1. Start Claude Code in a VS Code terminal and paste the prompt

    Anywhere else, reviews open in the browser instead of VS Code tabs.

  2. Answer your agent's questions

    Which parts you want (the review part is always included), whether you use superpowers or BMAD, whether you have access to the Fable model, whether you want the Rigor rules or the Dashboard (both need Node.js), and where to keep the repo.

  3. Say yes to Plannotator's install script

    If Plannotator is missing, your agent tells you it will run Plannotator's official install script, and waits for your OK.

  4. Restart VS Code when asked

    Close every VS Code window, reopen VS Code and start a new Claude Code session. A new terminal isn't enough: it keeps the old PATH.

  5. Turn on Board and Steps in the Inbox

    Open the Inbox, go to Settings > Capabilities, and turn both on. Allow notifications when it asks.

  6. Tick "Always allow" for VS Code links

    The first time you click a file link in the Inbox, your browser asks to open VS Code.

  7. Run the two checks with your agent

    A review tab opens in VS Code, and a sign-off goes to the Inbox with your answer coming back to the session.

What the end looks like

The installer finishes with a Summary, and your agent shows it to you.

Example 
== Summary
  1 thing(s) left to do:
    - rules/methods.md kept as yours. To replace it: ./install.ps1 -Components Review,Methods -Replace rules/methods.md
  Then: close every VS Code window, reopen VS Code, then start a new Claude Code session in its terminal.
exit 0Done. Nothing left to do.
exit 3Installed, but the Summary lists something for you: a file you changed, or a missing tool.

If something's off

You seeCause and fix
"Select an app to open 'open-in-vscode'"The session started before the install, or settings.json lost PLANNOTATOR_BROWSER. Run the installer again, then start a new session.
Reviews open in the browserThe session isn't in a VS Code terminal, or the Plannotator WebView extension isn't installed. That fallback is on purpose.
plannotator not foundIt was installed after VS Code started. Close every VS Code window and reopen VS Code.
No Board cards or checklistsBoard or Steps is off in the Inbox's Settings > Capabilities.
File links do nothingThe browser blocked VS Code links. Click one again and allow it.
Replies don't come backThe session started before Plannotator was installed. Start a new session.
Stuck anywhere elseSend the person who shared this your agent's Summary, or the point where it stopped.

Make it yours

Put your own preferences in a rule file of your own, such as ~/.claude/rules/my-review-tweaks.md. Claude loads every file in that folder, and updates never touch yours.

Install by hand, without an agent

Clone the repo, then run the installer. It asks which parts you want, never replaces a file you changed without asking, and ends with the same Summary.

PowerShell 7
git clone https://github.com/pmcormier/claude-visual-review
cd claude-visual-review
./install.ps1 -InstallTools

The Dashboard is optional: ./install.ps1 -Components Review,Dashboard (needs Node.js). It wraps your status line and adds a Start menu shortcut; ./install.ps1 -Remove Dashboard undoes both. Plans already in your repos fold under “Before the dashboard” until they show progress; run /dashboard catch-up in a project to have Claude check its older plans against the repo and mark the finished ones, after you approve.

BMAD projects: ./install.ps1 -Components Review,Methods,Bmad -BmadProject <project>. To update: git pull, then ./install.ps1; it reuses your components.
